## Sweep methodology

For each batch (T8.1–T8.4), each agent:

1. Reads the existing parity doc end-to-end.
2. Skims the rAthena `.cpp` for the function inventory.
3. Greps the C# tree for each public function's entry point.
4. Returns: matches (✅), partial-with-gap (⚠️), missing (❌), and
   doc-stale claims (where the doc says something the code now
   contradicts or the code now does something the doc doesn't
   mention).

Aggregated findings land in this doc's `## Findings` section
(populated by T8.1–T8.4).
